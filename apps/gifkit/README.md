# GifKit 1.0.0

Create animated GIFs from selected photos with adjustable frame delay.

Android 11+, English, Korean and Japanese. No network permissions, analytics, live advertising, billing, signing or publication. Development release; GitHub Actions build/lint and real-device testing required. User-selected files only. See the app for limits and unsupported capabilities.

The preview strip shows the current frame order. Use the localized move-earlier actions to reorder frames, then choose the maximum side and frame duration. The export opens Android's save picker. Input links and previews are kept for the current session. Temporary GIF exports are staged in app-private cache.
