# MeasureKit 1.0.0

Sensor level and inclinometer with zero calibration.

Android 11+, English, Korean and Japanese. No network permissions, analytics, live advertising, billing, signing or publication. Development release; GitHub Actions build/lint and real-device testing required. User-selected files only. See the app for limits and unsupported capabilities.

The dashboard shows a live bubble and two display-oriented angle readings. Set zero on a known level reference and reset to the sensor baseline when needed. Calibration lasts for the activity session and survives instance recreation. MeasureKit does not open, create or export files and requests no runtime permissions.
