# LEDKit 2.0.0

Offline scrolling LED banner with customizable colors, speed and fullscreen mode.

Scrolling text and fullscreen, no flashing mode. Android 11+, English, Korean and Japanese. No network, accounts, analytics, advertising or billing. Automated build and real-device verification required; release disabled.

Version 2 adds branded rounded controls, a large interactive visual panel and haptics. See DESIGN.md for scope and limitations. CI and device validation pending.

The live LED preview follows message, color, direction, speed and size changes. Static mode automatically fits long text and disables speed adjustment. Fullscreen starts only after the user taps it and can be closed with Android Back or a tap. Settings are written only when saving to this device.
