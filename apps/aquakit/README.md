# AquaKit 2.0.0

Offline illustrated aquarium, feed fish and unlock collectible species.

Six custom 2D illustrated aquatic creatures, local points and themes. No realism or online features. Android 11+, English, Korean and Japanese. No network, accounts, analytics, advertising or billing. Automated build and real-device verification required; release disabled.

Version 2 adds branded rounded controls, a large interactive visual panel and haptics. See DESIGN.md for scope and limitations. CI and device validation pending.
