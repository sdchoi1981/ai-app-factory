# CleanKit 1.0.0

Find byte-identical photos among up to 20 selected documents using SHA-256. Read-only report; no deletion. Android 11+, Korean, English and Japanese. No network, ads, tracking, or release enabled. Device testing pending.

Selected-photo previews and labeled side-by-side results help distinguish the first matching file from later copies. Unreadable files are counted separately. File contents are hashed in memory and results are session-only.
