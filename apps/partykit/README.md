# PartyKit 2.0.0

Offline decision wheel, coin toss, dice and family-friendly party prompts.

Random text choices and family challenges, animated decision wheel. Android 11+, English, Korean and Japanese. No network, accounts, analytics, advertising or billing. Automated build and real-device verification required; release disabled.

Version 2 adds branded rounded controls, a large interactive visual panel and haptics. See DESIGN.md for scope and limitations. CI and device validation pending.

The shared design system provides light and dark cards, accessible status announcements, and edge-to-edge layout. The wheel uses the same sector calculation for the animation and announced result. Choosing a quick game cancels any pending wheel result. Custom options remain in memory and are not saved when the activity is recreated.
