# PDFKit 1.0.0

Merge, extract and render PDF pages; rasterized PDF export.

Android 11+, English, Korean and Japanese. No network permissions, analytics, live advertising, billing, signing or publication. Development release; GitHub Actions build/lint and real-device testing required. User-selected files only. See the app for limits and unsupported capabilities.

The app uses the shared Kit design with localized, accessible previews. PDFKit previews the first selected PDF page and displays the total page count; output remains rasterized. Screenshots of the app are blocked to protect document contents.
