# SnakeKit / 뱀 탐험대

Child-focused Korean offline illustrated snake encyclopedia. First edition: 16 taxa, original stylized color/pattern illustrations (not accurate identification artwork or real photos), searchable Korean/English/scientific names, habitat and family-group filters, local favorites, fact quizzes and safety education. No ads, network permission, analytics, account, external links or child data collection. Local favorites are stored only in WebView localStorage. Group filters are educational groupings rather than full phylogenetic taxonomy. Korean common names may vary; scientific names are included. Source URLs are displayed as text in detail view for adult reference. Source facts paraphrased, no source photos copied. Real photo licensing, content expansion, accessibility and real-device checks remain pending. Not a field identification or handling guide.
