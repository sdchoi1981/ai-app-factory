# DateKit

Native offline date utility: signed date differences, inclusive days, D-day from device local date, signed day offsets. Android 8.0+ (API 26), target API 36. Reuses factory UI theme and system insets. English, Korean and Japanese. Calendar days, not elapsed 24-hour periods or working days. Supported dates 1900–9999. No network permission, ads, analytics or account. Java 17 is needed for the calculation tests. Device interaction, package ID availability on Play, signing and publication are not verified.
