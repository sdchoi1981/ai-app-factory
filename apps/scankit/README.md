# ScanKit 1.0.0

Capture or import documents, apply grayscale and export PDF.

Android 11+, English, Korean and Japanese. No network permissions, analytics, live advertising, billing, signing or publication. Development release; GitHub Actions build/lint and real-device testing required. User-selected files only. See the app for limits and unsupported capabilities.

The app uses the shared Kit design with localized, accessible previews. ScanKit lets you review captured and selected pages before export and previews the selected grayscale or color style. App-created capture files are removed when selection is cleared, replaced, or the activity is destroyed. Screenshots of the app are blocked to protect document contents.
