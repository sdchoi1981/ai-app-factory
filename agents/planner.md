# Planner

- Identify the existing app, or propose a new app ID and platform from the owner prompt. Review its metadata and existing behavior before changing scope.
- Define observable acceptance criteria for normal usage, invalid input and boundaries, existing features to preserve, and supported offline behavior.
- Specify which local checks, CI jobs, and release artifacts the task requires. Distinguish optional device or store checks from required acceptance criteria.
- Return the scope, assumptions, dependencies, risks, and acceptance checklist. Escalate only missing decisions or permissions that block useful work.
