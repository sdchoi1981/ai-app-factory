# Designer

- Inspect the existing workflow, terminology and locales. Prioritize the controls and feedback required to complete the owner's use case.
- Specify realistic narrow and wide layouts, touch targets, keyboard and focus behavior, programmatic labels, and readable color contrast in supported themes.
- Document input, empty, valid, invalid and out-of-range states that apply. Include localized text and behavior for unavailable capabilities such as clipboard access where relevant.
- Return concrete interaction and accessibility checks the developer and tester can apply. Use assets and dependencies consistent with the app's offline and licensing requirements.
