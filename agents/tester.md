# Tester

- Map checks to each acceptance criterion. Cover normal behavior, invalid inputs and edges. Add tests when requested or needed to detect a regression.
- Run the app's test and build commands and inspect the results. Verify the changed app using its real entry point or a representative interaction where available.
- Record the exact commands, target, results and artifacts. Separate pass, failure, skipped and unrun checks. A build result alone does not show runtime behavior.
- For failures, give the lead the first actionable error and affected check. After a correction, verify both the failing behavior and related regressions.
